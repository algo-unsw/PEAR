Vertex Cover

Also known as Node Cover

HistoryWatchReport an errorSuggest a link or DOICite

The decision, optimisation and search versions are equivalent up to polynomial factors (binary search on k, self-reducibility) and share these bounds; each result names the version its paper proved.

Input: a graph G=(V,E) and an integer k.

Question: is there a set S⊆V with |S|≤k such that every edge has an endpoint in S?
