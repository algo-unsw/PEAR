Vertex Cover

Also known as Node Cover

HistoryWatchReport an errorSuggest a link or DOICite

The decision, optimisation and search versions are equivalent up to polynomial factors (binary search on k, self-reducibility) and share these bounds; each result names the version its paper proved.

Fastest known algorithms

By solution size

O*(1.2738k), deterministic and in polynomial space [1]. Exact form O(1.2738k+kn); proved for the [version].

By number of vertices

O*(1.1996n), deterministic and in polynomial space, from the algorithm for Maximum Independent Set [2]. derived

By treewidth

O*(2tw) by dynamic programming over a tree decomposition, in exponential space. Exact form 2tw⋅twO(1)⋅n.

Input: a graph G=(V,E) and an integer k.

Question: is there a set S⊆V with |S|≤k such that every edge has an endpoint in S?

Reductions

  • From Maximum Independent Set and Clique, each with k↦n−k.
  • To Set Cover and d-Hitting Set, each with k↦k; the Set Cover reduction also works for the weighted version.

Related problems

Complement: Independent Set, Clique. Variants: Connected Vertex Cover. Generalisations: d-Hitting Set, Set Cover. Counting and enumeration: #Vertex Cover, minimal vertex covers.

References
